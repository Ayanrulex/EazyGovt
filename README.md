# EazyGovt — Phase 1.1 Frontend Foundation

EazyGovt is an independent citizen-guidance platform concept for discovering Indian government services and reaching the correct official portals.

## What this version contains
- Responsive landing page
- Original EazyGovt visual identity
- Service discovery UI
- Popular services and category browsing
- AI assistant concept
- Location/office locator concept
- Login/signup entry points
- Light/dark mode
- Accessibility skip link
- Independent-platform disclaimer
- Official-source-first policy
- Official India.gov.in reference links
- Multilingual and location roadmap placeholders
- Interactive category/state/search prototype behavior

## What it does NOT claim yet
This is a frontend prototype. It does not yet provide production authentication, live AI, official application submission, live application status, a nationwide verified service database, or production map integration.

## Product rule
EazyGovt helps users discover, understand and navigate to government services. The official government portal remains authoritative. Each production service record will store its official source, department, applicability, requirements and last verification date.
